# 资料契约

本目录只含本地合成记录，不包含真实驾驶员、车辆或道路资料。新闻报道描述的是厂商发布信息及公开说明，不是本资料集中的实测结论。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `sessions.csv` | `session_id`, `driver_key`, `version`, `wear`, `lighting`, `task_minutes`, `camera_state`, `prompt_count`, `region` | 60 |
| `feedback.csv` | `response_id`, `driver_key`, `session_id`, `survey_wave`, `submitted_at`, `rating`, `consent_scope` | 20 |
| `annotations.csv` | `annotation_id`, `session_id`, `reviewer`, `attention_label`, `visibility`, `review_batch` | 24 |
| `research_slots.csv` | `slot_id`, `region`, `device`, `wear_condition`, `date`, `capacity`, `consent_state`, `status` | 21 |

输入文件之间通过明确的标识字段关联。记录时间均为 UTC 或 ISO 日期。缺失覆盖、待复核和撤回状态是有效业务事实，不能自动解释为零事件或成功。事件标签、回执、版本和授权范围以各行记录为准。所有示例数值由固定种子构造，仅供本地数据流程开发与测试。

应用侧（`src/driver_attention_monitoring_review/`）只读这些 CSV：

- 导入时执行受控词表、整数范围、外键引用与重复主键校验，任一行不合规则整批拒绝；
- 行级内容哈希用于幂等导入，同主键内容变化会被拒绝而不是覆盖历史；
- 运营状态（证据快照、决策、研究计划、名额事件、资料处置）保存在独立状态库，
  不回写本目录；口径见 `指标口径说明.md`，流程见 `运营流程与审计说明.md`。
